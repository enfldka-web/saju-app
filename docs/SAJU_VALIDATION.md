# 사주 계산 엔진 검증 (Phase 1)

`lib/saju/calculate.ts`는 [`lunar-javascript`](https://github.com/6tail/lunar-javascript)(1.7.7) 위에서
결정론적으로 사주 원국·오행·대운을 계산한다. 이 문서는 그 출력값을 사람이 직접 대조 검증할 수 있도록 정리한 것이다.

**진행 방식**: 아래 표를 사용자님이 신뢰하는 다른 만세력(예: 본인 생년월일시, 만세력 앱/사이트)과 대조해 주세요.
전부 일치하면 계산 엔진을 확정하고 AI 해석 레이어 + UI 작업(Phase 1 다음 단계)으로 넘어가겠습니다.

## 1. 자동 테스트 (14개, 모두 통과)

`npm test` 로 실행. 결정론성, 윤달 변환, 입춘 등 절기 경계, 자시 처리, 성별별 대운 순행/역행, 입력 검증을 커버한다.

```
✓ calculateSaju - 결정론성 (1)
✓ calculateSaju - 스펙 샘플: 1981-02-11 19:30 양력 남성 (3)
✓ calculateSaju - 출생시간 미상 (1)
✓ calculateSaju - 윤달(음력) 처리 (2)
✓ calculateSaju - 자시(子時) 경계 처리 ★검증 필요 (3)
✓ calculateSaju - 성별에 따른 대운 순행/역행 (1)
✓ calculateSaju - 입력 검증 (2)
✓ computeOhaengDistribution (1)
```

## 2. ⚠️ 사용자 확인이 꼭 필요한 것: 자시(子時) 경계 규칙

한국 사주 커뮤니티에서도 의견이 갈리는 지점입니다 — 23:00~24:00 출생을 "당일"로 볼지 "다음날"로 볼지.

| 규칙 | 설명 | 결과 (2024-03-15 23:30 출생 기준 일주) |
|---|---|---|
| `next-day` (기본값) | 23:00부터 자시=다음날로 취급 (조자시/야자시 구분 없음) | **기묘일** (2024-03-16 00:30 출생과 동일) |
| `traditional` | 23:00~24:00은 당일 일주 유지, 00:00 이후에만 다음날 | **무인일** (2024-03-15 정오 출생과 동일) |

- 대부분의 최신 한국 만세력 앱/웹은 `next-day`(23시부터 다음날) 방식을 기본으로 씁니다. 일단 이걸 기본값으로 설정해뒀습니다.
- 만약 사용자님이 참고하는 만세력이 조자시/야자시를 구분하는 전통 방식이라면 `traditional`로 바꿔야 합니다.
- **확인 요청**: 이 두 결과 중 어느 쪽이 맞는지, 혹은 다른 기준(예: 태어난 지역 표준시 보정 등)이 필요한지 알려주세요.

## 3. 샘플 검증 케이스

### 3-1. 기본 샘플 (1981-02-11 19:30, 양력, 남성)

| 항목 | 값 |
|---|---|
| 연주 | 신유(辛酉) — 금금 |
| 월주 | 경인(庚寅) — 금목 |
| 일주 | 경신(庚申) — 금금 |
| 시주 | 병술(丙戌) — 화토 |
| 오행 분포 | 목1 화1 토1 **금5** 수0 |
| 대운수 | 3세 시작, 역행(逆行) |
| 대운 목록 | 3-12 기축(1983) · 13-22 무자(1993) · 23-32 정해(2003) · 33-42 병술(2013) · 43-52 을유(2023) · 53-62 갑신(2033)... |

### 3-2. 1995-08-20 06:00, 양력, 여성

연주 을해(木水) · 월주 갑신(木金) · 일주 계미(水土) · 시주 을묘(木木)
오행: 목4 화0 토1 금1 수2 / 대운수 8세, 순행(順行)

### 3-3. 2000-01-01 00:20, 양력, 남성 (연도 경계 근처 — 연주가 1999년으로 안 넘어가는지 확인용)

연주 기묘(己卯) · 월주 병자(丙子) · 일주 무오(戊午) · 시주 임자(壬子)
→ 자시(00:20)라도 절입 기준 **연주는 여전히 기묘(2000년생 그대로)**가 나옴 — 연주는 입춘 기준으로 바뀌므로 정상.

### 3-4. 윤달 처리 (음력 1990년 5월 10일, 14:00, 여성)

| | 평달(5월) | 윤달(윤5월) |
|---|---|---|
| 변환된 양력 | 1990-06-02 | 1990-07-02 |
| 월주 | 신사(辛巳) | 임오(壬午) |
| 일주 | 무술(戊戌) | 무진(戊辰) |
| 오행 분포 | 목0 화2 토4 금2 수0 | 목0 화2 토4 금1 수1 |

→ `isLeapMonth` 플래그로 정확히 다른 날짜(약 한 달 차이)로 변환되고, 그 결과 월주/일주가 달라짐을 확인.

### 3-5. 입춘(立春) 절기 경계 (1990-02-04, 남성)

1990년 입춘은 2월 4일 낮 시간대. 같은 날짜라도 입춘 전/후로 **연주가 바뀌는지** 확인:

| | 06:00 (입춘 전 추정) | 20:00 (입춘 후 추정) |
|---|---|---|
| 연주 | 기사(己巳, 1989년생 취급) | 경오(庚午, 1990년생 취급) |
| 월주 | 정축(丁丑) | 무인(戊寅) |
| 대운 순행 | 역행 | 순행 |

→ 절기 경계를 실제로 넘기면서 연주/월주/대운 방향까지 바뀌는 것을 확인. **가장 중요하게 대조 검증해주셔야 할 케이스입니다.**
(정확한 1990년 입춘 시각은 공식 자료로 별도 재확인 권장)

## 4. 알려진 제한사항 (Phase 1 범위)

- 출생지 표준시/서머타임 보정은 하지 않음 (한국 표준시 고정 가정). 해외 출생자 지원은 Phase 2+ 검토.
- 대운 계산은 출생시간 미상일 경우 정오(12:00) 기준으로 근사 계산되어 정밀도가 낮아짐 (연/월/일주에는 영향 없음, 시주만 비표시).
- 지장간(숨은 천간)은 표시용으로만 제공, 해석 로직에는 아직 반영하지 않음.
